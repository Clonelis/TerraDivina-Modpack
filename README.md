# TerraDivina Modpack

Этот репозиторий управляет содержимым TerraDivina Launcher без отдельного сервера.

## Конфиги

Загрузите нужные файлы в папку `config`, сохраняя их настоящую структуру. GitHub Actions автоматически добавит их в `configFiles` файла `manifest.json`, рассчитает SHA-256 и создаст прямые Raw GitHub-ссылки.

По умолчанию конфиги обновляются принудительно. Чтобы сохранить пользовательские изменения конкретного файла, после автоматического обновления манифеста замените у него `"overwrite": true` на `"overwrite": false`.

## Моды

1. Откройте раздел Releases и создайте новый релиз.
2. Прикрепите к нему `.jar`.
3. Скопируйте прямую ссылку файла релиза.
4. Добавьте мод в массив `mods` файла `manifest.json`.

Пример записи:

```json
{
  "id": "create",
  "name": "Create",
  "version": "6.0.6",
  "file": "create-1.21.1-6.0.6.jar",
  "url": "https://github.com/Clonelis/TerraDivina-Modpack/releases/download/pack-1/create-1.21.1-6.0.6.jar",
  "sha256": "64-символьная-контрольная-сумма",
  "modrinth": "create"
}
```

Поле `modrinth` используется для иконки и ссылки на страницу мода.
