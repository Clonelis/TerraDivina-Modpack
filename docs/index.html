Модпак для тех, кто не может воспользоваться нашим лаунчером для Windows. Подходит для ручной установки на macOS, Linux и Windows.

Minecraft 1.21.1 NeoForge 21.1.250
Скачать сборку

ZIP-архив: моды, конфигурации и ресурс-паки.

Актуальная сборка обновляется автоматически через GitHub.

Как установить

  1. 01Установи Minecraft Java 1.21.1 и NeoForge 21.1.250 в своём лаунчере.
  2. 02Скачай ZIP-архив и открой папку игры для созданного профиля.
  3. 03Перенеси папки mods, config и resourcepacks из архива в папку игры. Запусти Minecraft.

Рекомендуем отдельный профиль игры, чтобы не затронуть другие моды и настройки. Совместимость отдельных модов с macOS может зависеть от устройства.
