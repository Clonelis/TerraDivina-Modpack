Установка

  1. 01

    Подготовь игру

    Установи Minecraft Java 1.21.1 с NeoForge 21.1.250.

  2. 02

    Распакуй сборку

    Скачай ZIP и перенеси папки mods, config и resourcepacks в папку игры.

  3. 03

    Запускай

    Выбери подготовленный профиль, запусти игру и подключайся к серверу.

Лучше использовать отдельный профиль, чтобы файлы сборки не смешивались с другими модами.
